# AUTOMOTIVE MARKET ANALYSIS – POWER BI

## PROJECT OVERVIEW
An interactive Power BI dashboard developed to analyze automotive market trends, vehicle pricing, manufacturer performance, fuel type preferences, and vehicle age distribution.

## OBJECTIVE
To transform raw automotive data into meaningful insights and identify key market trends through data analysis and visualization.

## TOOLS & TECHNOLOGIES
Microsoft Power BI, Power Query, DAX, Microsoft Excel.

## KEY IMPLEMENTATIONS
- Developed interactive dashboards and KPI cards.
- Analyzed manufacturer-wise market share.
- Evaluated vehicle price segments and price variations.
- Compared petrol, diesel, and hybrid vehicle distribution.
- Analyzed vehicle manufacturing year trends.
- Implemented interactive slicers and data visualizations.
